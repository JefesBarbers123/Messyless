# MESSYLESS — one-page launch site

A no-framework, single-page static website built around the original hand-drawn Messyless character and logo supplied by the founder.

## What is included
- One-page responsive website
- Menu based on the supplied Doughnut Burger Production Guide
- Launch deal: 50% off fries for people joining with a mobile number
- Email + optional mobile capture form
- Paperback book section at £5.99
- Stripe Payment Link placeholder
- Formspree endpoint placeholder
- No database, framework or paid hosting required

## Before launch
1. Open `index.html`.
2. Replace `YOUR_STRIPE_BOOK_PAYMENT_LINK` with your Stripe Payment Link for the £5.99 paperback.
3. Replace `YOUR_FORMSPREE_ENDPOINT` with your Formspree form endpoint.
4. Replace `@YOURHANDLE` with the real social handle.
5. Add a real privacy-policy link and confirm your marketing consent wording.
6. Replace the `£ —` menu prices once final menu pricing is set.

## Free hosting
This is plain HTML/CSS/JS, so it can be hosted on GitHub Pages or Cloudflare Pages. The site itself has no server requirement.

## Images

## Important operational note
The burger descriptions/menu pairings are based on the supplied production guide. The site intentionally does not invent menu prices.
